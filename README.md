# ENGR-4399-ST-Cyber-Physical-IoT-Systems-Project-1
Project 1, Greenhouse monitoring system using an Esp32. Collecting data, display it on Adafruit, connect to weather api and respond to that data.

The project uses a DHT11, OLED screen, thermistor, a servo, Openweather API, and Adafruit API. All work together, gathering data and responding accordingly. If thunderstorms are in the forecast, the greenhouse would open its ceiling for nitrogen and rain. If the temperature is unbalanced and too hot indoors, then the ceiling opens up to release the heat. The soil moisture sensor keeps track on the moisture levels in soil and sends the data to the olde display and Adafruit dashboard.
Claude and ChatGPT were used in learning and helping debug.
